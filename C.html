C Language

General-purpose procedural programming for system-level development

Introduction to C

C is a general-purpose, procedural computer programming language supporting structured programming, lexical variable scope, and recursion. It was developed in 1972 by Dennis Ritchie at Bell Labs and has become one of the most widely used programming languages of all time.


C provides low-level access to memory, a simple set of keywords, and a clean style — these qualities make C suitable for system programming like an operating system or compiler development.

Why Learn C?

  • C is widely used worldwide and forms the basis of many other languages.
  • It is efficient and highly portable across platforms.
  • It provides low-level memory access with pointers.
  • C is the language of operating systems like Linux and Windows kernel.
  • Learning C gives you a deeper understanding of how computers work.
  • It has a large and active community with extensive resources.

C Basics

Hello World

#include <stdio.h> int main() { printf("Hello, World!"); return 0; }

Simple Addition

#include <stdio.h> int main() { int num1 = 5; int num2 = 10; int sum = num1 + num2; printf("The sum is: %d", sum); return 0; }

Simple Loop

#include <stdio.h> int main() { for (int i = 1; i <= 5; i++) { printf("Count: %d\n", i); } return 0; }

C Features

⚙️ Procedural Language

C follows a sequence of steps (procedures) to achieve desired outcomes.

🔧 Low-Level Access

C provides low-level access to memory and system resources via pointers.

🌐 Portability

C code is highly portable and can run on various platforms with minimal changes.

⚡ Efficiency

Known for high performance, making it suitable for resource-intensive applications.
